# croffle-server release notes

한국어: 아래 참조.

One file per server release: `<version>.md` (for example `0.1.0-rc.1.md`, `0.1.0.md`), committed in the release PR. The server is distributed as the `ghcr.io/team-croffle/croffle-server` image and **never** gets a GitHub Release, because a release there would become the repository's latest release and stop the desktop app from updating.

The template and writing rules are in [`.github/release-notes.md`](../../../.github/release-notes.md#server).

---

서버 릴리스마다 `<version>.md` 파일 하나를 릴리스 PR에 커밋합니다. 서버는 ghcr 이미지로만 배포하고 GitHub Release는 만들지 않습니다. 만들면 저장소의 최신 릴리스가 되어 데스크톱 앱 업데이트가 멈추기 때문입니다. 템플릿은 [`.github/release-notes.md`](../../../.github/release-notes.md#server)에 있습니다.
