# croffle-server v0.1.0

Image: `ghcr.io/team-croffle/croffle-server:0.1.0` (also `:latest`) · tag `server-v0.1.0` · protocol `1`–`1`

The first release of the optional self-hosted sync server for Croffle (beta). It is one Go binary with one SQLite file, and it is the server that desktop 1.3.0's sync (beta) talks to. Nothing in the desktop app needs it: Croffle works fully without a server. The code is the same as `0.1.0-rc.1`, which desktop 1.3.0 was verified against.

## Overview

- **Accounts and device tokens** — argon2id passwords; `POST /auth/login` issues an opaque token per device (only its hash is stored), `POST /auth/whoami` checks it. An OTP field is reserved.
- **Sync API** — `POST /sync/push` applies a batch of changes idempotently (`opId`) in one transaction and reports conflicts with the server's row (HTTP 200 + `conflicts[]`); `POST /sync/pull` serves the commit log from a cursor; `POST /sync/bootstrap` sends a paged snapshot to a new or stranded device.
- **Retention** — the commit log keeps 90 days by default (`CROFFLE_RETAIN_COMMITS_DAYS`); a cursor older than that gets 410 and the device re-bootstraps. Expired history and idempotency keys are swept daily.
- **Operator commands** — accounts, tokens, the team and the commit log, run against the database file.
- **Read-only dashboard** — sign in and see your own rows, embedded in the binary.
- **Hooks and a signed webhook** — observe commits from outside without changing them.
- `GET /health` reports the server version, the protocol range, database state, retention and the server clock.

## Upgrade notes

- From `0.1.0-rc.1`: nothing to do beyond changing the image tag to `0.1.0`; there is no schema or configuration change. `:latest` now points at this release.
- Put TLS in front of it (Caddy, Traefik, nginx, an ingress). The server speaks plain HTTP. It honours `X-Forwarded-*` only when `CROFFLE_TRUST_PROXY=true` (off by default); turn it on only behind a proxy you trust.
- Setup and configuration: [apps/server/README.md](../../../apps/server/README.md).

## Compatibility

- Desktop 1.3.x (sync protocol 1). Desktop 1.3.0 was verified against `0.1.0-rc.1` on Linux and Windows; macOS has not been verified yet.

## Known limitations

- Beta: one team. Sharing cannot be undone yet; tags and reminders are not shared along with a schedule.
- Tokens do not expire (no refresh tokens yet).
- The dashboard is read-only; no metrics.
- Disabling an account blocks it but does not erase its data.

# croffle-server v0.1.0

선택적으로 쓰는 Croffle 셀프호스트 동기화 서버의 첫 릴리스(beta)입니다. Go 바이너리 하나와 SQLite 파일 하나로 동작하며, 데스크톱 1.3.0의 동기화(beta)가 붙는 서버입니다. 데스크톱 앱은 서버 없이도 모두 동작합니다. 코드는 데스크톱 1.3.0을 검증한 `0.1.0-rc.1`과 같습니다.

## 변경 사항

- 계정과 기기별 토큰 (argon2id, 토큰은 해시만 저장, OTP 자리 마련)
- 동기화 API: 멱등 push와 충돌 보고, 커서 pull, 새 기기용 bootstrap
- 커밋 로그는 기본 90일 보존(`CROFFLE_RETAIN_COMMITS_DAYS`), 보존 밖 커서는 410 후 다시 bootstrap. 만료 기록은 매일 정리
- 운영 명령(계정 · 토큰 · 팀 · 커밋 로그), 읽기 전용 대시보드, 훅과 서명된 웹훅
- `/health`가 서버 버전 · 프로토콜 범위 · DB 상태 · 보존 상태 · 서버 시각을 알려 줍니다

## 업그레이드 안내

- `0.1.0-rc.1`에서 올릴 때는 이미지 태그만 `0.1.0`으로 바꾸면 됩니다. 스키마와 설정 변경이 없습니다. `:latest`가 이 릴리스를 가리킵니다.
- TLS는 앞단 프록시에서 처리합니다. `X-Forwarded-*`는 `CROFFLE_TRUST_PROXY=true`일 때만 따르며(기본 꺼짐), 믿을 수 있는 프록시 뒤에서만 켜십시오. 설치와 설정은 [apps/server/README.ko.md](../../../apps/server/README.ko.md)를 참고하십시오.

## 호환

- 데스크톱 1.3.x (동기화 프로토콜 1). 데스크톱 1.3.0은 `0.1.0-rc.1`을 대상으로 Linux와 Windows에서 검증했고 macOS는 아직입니다.

## 알려진 한계

- beta입니다. 팀은 하나뿐이고, 공유 취소와 태그 · 리마인더 동반 공유는 아직 없습니다.
- 토큰은 만료되지 않습니다. 대시보드는 읽기 전용이고 metrics가 없습니다.
- 계정을 비활성화하면 접속은 막히지만 데이터는 지워지지 않습니다.
